# Tsehay Campus ☀️

የኢትዮጵያ ምርጡ እና በ AI (Artificial Intelligence) የታገዘ የኦንላይን መማሪያ ፕላትፎርም። (The #1 AI-Powered Online Learning Platform in Ethiopia).

## 🚀 ዋና ዋና ገፅታዎች (Features)
- **Tsehay AI Assistant:** 24/7 ጥያቄ የሚመልስ እና የቢዝነስ ትንታኔ የሚሰጥ AI።
- **Premium Courses:** በተግባር ላይ ያተኮሩ የቪዲዮ ስልጠናዎች።
- **AI Quiz & Certificates:** ትምህርቱ ሲጠናቀቅ በ AI የሚዘጋጅ ፈተና እና ዲጂታል ሰርተፍኬት።
- **Real-time Dashboard:** የተማሪዎችን የትምህርት ሂደት (Progress) መከታተያ።

## 🛠️ የተጠቀምናቸው ቴክኖሎጂዎች (Tech Stack)
- **Frontend:** HTML5, Tailwind CSS, JavaScript
- **Backend & Database:** Firebase (Auth, Firestore)
- **AI Integration:** Google Gemini API (via Vercel Serverless Functions)
- **Deployment:** Vercel
